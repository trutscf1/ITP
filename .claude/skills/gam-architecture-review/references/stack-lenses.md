# Stack lenses

Part of areas 3, 4, 6, and 7 of [score.md](score.md). The skill holds no copy of any framework's rules: for each part of the stack the project uses, call the Skill tool with the technology skill `STACK.md` §10 binds for that situation (P-DES-7), and fold its findings into the area rows.

| Part of the stack | Area | Skill to call |
| --- | --- | --- |
| React, components | 7 | the one §10 binds for screens and controls |
| Next.js | 3, 7 | the one §10 binds for framework conventions |
| Prisma or another ORM | 6 | the one §10 binds for data access |
| Better Auth or another auth library | 4 | the one §10 binds for authentication |
| Security in general | 4 | `security-review` or the one §10 binds |
| Production readiness | 9, 10 | `gam-v-pre-release-review` for the delivery items |

A row with no bound skill is read from the library's documentation and named in the report as unbound; another installed skill is not substituted. A part the project does not use is not listed.
