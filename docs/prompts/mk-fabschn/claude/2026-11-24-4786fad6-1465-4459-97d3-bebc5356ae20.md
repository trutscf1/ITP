### 21. Answer (2026-11-25T06:10:04.660Z)

````text
Diese Zeile verbindet ein Formular mit einer Server Action in React 19 / Next.js. Typisch ist das Zusammenspiel von `react-hook-form` (oder einer ähnlichen Validierung) mit `useActionState`.

```ts
onValid: (data) => startTransition(() => dispatch(data))
```

**1. `onValid: (data) => …`** ist der Callback, den die Formularbibliothek **nur bei gültigen Eingaben** aufruft. Das ist zum Beispiel der erste Parameter von `handleSubmit(onValid, onInvalid)` in react-hook-form. `data` enthält die bereits validierten Werte, oft schon durch ein zod-Schema geprüft und typisiert. Bei Validierungsfehlern wird stattdessen `onInvalid` aufgerufen, und es geht gar nichts an den Server.

**2. `dispatch(data)`** kommt typischerweise aus

```ts
const [state, dispatch, isPending] = useActionState(serverAction, initialState);
```

`dispatch` stößt die Server Action an. Deren Ergebnis, etwa „Fehler: E-Mail vergeben“ oder „erfolgreich“, landet danach in `state`.

**3. `startTransition(() => …)`** braucht es, weil React den `dispatch` von `useActionState` in einer Transition erwartet. Bei `<form action={dispatch}>` erledigt React das automatisch. Hier wird aber manuell aus einem Callback heraus aufgerufen, deshalb muss man selbst einwickeln.

Ohne die Transition passieren zwei Dinge:
- React gibt die Warnung *„An async function was passed to useActionState, but it was dispatched outside of an action context“* aus.
- `isPending` wird nicht `true`, sodass ein Lade-Spinner oder ein deaktivierter Button nicht funktioniert.

Die Transition hat außerdem einen Vorteil für die Bedienung: Das Update gilt als nicht dringend, die Oberfläche bleibt währenddessen bedienbar.

**Ablauf zusammengefasst:**
1. Die Person schickt das Formular ab.
2. Die Validierung auf dem Client prüft die Eingaben. Bei Fehlern bleibt alles lokal, und die Fehlermeldungen erscheinen direkt am Feld.
3. Sind die Eingaben gültig, startet `startTransition` die Transition, `isPending` wird `true`, und `dispatch(data)` ruft die Server Action auf.
4. Die Antwort des Servers landet in `state`, und `isPending` wird wieder `false`.

Woher `startTransition` kommt, ist dabei egal. Es kann der Import aus `react` sein oder das Ergebnis von `useTransition()`. Wichtig ist nur, dass der Aufruf von `dispatch` innerhalb der Transition passiert.
````
