### 4. Answer (2026-11-17T13:52:36.089Z)

````text
`implement` ist kein eigener Skill. Es ist ein Befehl im Skill **`gam-delivery`**:

- Skill: `.claude/skills/gam-delivery/SKILL.md` (Befehlstabelle in Zeile 15, Abschnitt „Implement“ ab Zeile 48)
- Ablauf: `.claude/skills/gam-delivery/references/implement.md`
- Für mehrere Issues parallel: `.claude/skills/gam-delivery/references/implement-all.md`

**So startest du ihn:**

```
/gam-engineering implement <issue>
```

oder direkt `/gam-delivery implement <issue>`, zum Beispiel `/gam-delivery implement 116`.

Laut `CLAUDE.md` sollst du über `/gam-engineering` einsteigen, weil das der Router für den ganzen Ablauf ist. Er erstellt den Work-Branch von `dev`, arbeitet testgetrieben mit `gam-v-tdd`, schreibt Commits mit den Requirement-IDs, macht das Code-Review, öffnet den MR und geht dann zum Merge weiter.

Beachte: #116 ist ein Konzept-Issue. Dafür ist eher `/gam-concept` zuständig als `implement`.
````
